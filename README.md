# Expense Tracker Website

A monthly expense tracking web application that helps users record, manage, and monitor their daily expenses.

## Features

- User registration and login
- Daily expense tracking
- Separate expense categories:
  - Breakfast
  - Lunch
  - Dinner
  - Extra expenses
- Automatic daily and monthly total calculations
- Custom monthly expense cycles
- Expense history page
- Cloud data storage
- Responsive website for laptop and mobile devices

## Technologies Used

- HTML
- CSS
- JavaScript
- Supabase (Authentication and Database)
- Netlify (Deployment)
- Git and GitHub (Version Control)

## How to Run Locally

1. Clone the repository.
2. Open the project folder in VS Code.
3. Configure your Supabase project credentials.
4. Run the website using Live Server.
